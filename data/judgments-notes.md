# Relevance judgments

25 descriptive queries, each with ten explicitly selected corpus records: 250 query–song judgments. Lists are assistant-curated editorial expectations, ordered roughly from closest to broader thematic matches. They are not generated by automatically labeling the current top search results. The original single-reference benchmark was inspected before expanding the labels; this is not a blind held-out evaluation. No ranking weights were tuned on the expanded set.

The first entry retains the original seed reference. Additional entries include partial thematic matches when a query is very specific, and some cover versions. For example, the young-lovers query includes broader family/social opposition and two performances of “Romeo And Juliet”; those are separate corpus records, not distinct compositions. Other broad themes overlap across queries. Titles and artist credits are resolved directly from the dataset and can contain source errors.

All ten IDs count equally as relevant for Precision@K, Recall@K and MRR. Their editorial order does not add graded relevance or require an exact ranking match. These judgments are not human-validated or exhaustive: unlabeled songs can be relevant, so measured precision is reference agreement rather than a complete assessment of search quality.

The UI displays the expected lists before evaluation and supports collecting and evaluating custom labels directly. Browser labels persist per catalogue; optional JSON export remains available. Use pooled human judgments, a separate development set for tuning, and a held-out test set for a stronger study. No judgment text is added to the search index.
